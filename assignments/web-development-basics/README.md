# 📘 Assignment: Web Development Basics

## 🎯 Objective

Build a simple interactive website using HTML, CSS, and JavaScript.

## 📝 Tasks

### 🛠️	Create the HTML Structure

#### Description
Create an HTML file named `index.html` with basic elements including a title, heading, paragraph, and a button.

#### Requirements
Completed website should:

- Include a page title in the `<title>` tag
- Have an `<h1>` heading
- Contain a paragraph of text
- Include a button element


### 🛠️	Style with CSS

#### Description
Add CSS to style the HTML page, making it visually appealing with colors, fonts, and layout.

#### Requirements
Completed website should:

- Change the background color of the page
- Style the heading with a different font or color
- Add padding or margins to elements for better layout


### 🛠️	Add Interactivity with JavaScript

#### Description
Use JavaScript to make the button interactive, such as changing the text of the paragraph when clicked.

#### Requirements
Completed website should:

- Include JavaScript code that responds to button clicks
- Change the content of the paragraph when the button is clicked
